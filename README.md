# مُرشد العمرة — دليل مصوَّر بالواقع المعزّز

دليلٌ يرافق المعتمر داخل المسجد الحرام فيبيّن له في كل لحظة: **أين هو الآن، وفي أي شوطٍ
هو، وما المهمّة التالية، وإلى أين يتوجّه** — وفق صفة العمرة الثابتة في السنّة.

الفكرة امتدادٌ لمشروع `Museum_AR`، غير أن الغاية هنا **الإرشاد أثناء أداء عبادة** لا
العرض، وهذا يفرض قيوداً لم تكن هناك: الدقّة الشرعية، وألّا يحكم الجهازُ على النُّسك،
وألّا يضيع التقدّم إذا أُقفل الهاتف.

## التشغيل

الموقع ثابتٌ بالكامل، لا يحتاج خادماً ولا بناءً:

```bash
npx http-server -p 8099
# ثم افتح http://127.0.0.1:8099
```

> التتبّع بالكاميرا وتحديد الموقع يحتاجان `https` أو `localhost` في المتصفّحات الحديثة.

## بنية المشروع

| الملف | الوظيفة |
|-------|---------|
| `index.html` | شاشة الاستقبال: التعريف، مراحل العمرة، ما قبل الإحرام |
| `guide.html` | المرشد الحيّ: الكاميرا وطبقة الواقع المعزّز ولوحة الحالة |
| `manasik.html` | دليل المناسك النصّي الكامل، يُقرأ بلا كاميرا |
| `sources.html` | المصادر وحدود استعمال الدليل |
| `js/rites.js` | نموذج المناسك: المراحل والأحكام والأذكار والإحداثيات — **بيانات صِرفة** |
| `js/geo.js` | دوال هندسية: المسافة، السمت، فرق الزوايا، الإسقاط على مستقيم |
| `js/tracker.js` | محرّك التتبّع: يجمع الماركرات وتحديد الموقع والعدّاد اليدوي في حالةٍ واحدة |
| `js/guide.js` | ربط المحرّك بالواجهة، والبوصلة، ووضع المحاكاة |
| `js/i18n.js` | نظام الترجمة والمظهر |

الفصل بين البيانات والمنطق والواجهة مقصود: **تصحيح نصٍّ شرعيٍّ أو إحداثيةٍ يجب ألّا يمسّ
منطق العدّ**.

## كيف يُحتسب الشوط؟

ثلاثة مصادر تغذّي حالةً واحدة، ومصدر كل شوطٍ **معلَنٌ على الشاشة** فلا يقع عدٌّ خفيّ:

1. **الماركرات** — أربع صورٍ عند الحجر الأسود ومقام إبراهيم والصفا والمروة، تُمسح
   بالكاميرا عبر MindAR، ولها زمن تبريدٍ يمنع العدّ المضاعف في الوقفة الواحدة.
2. **تحديد الموقع** — في الطواف تُراكَم الزاوية المقطوعة حول الكعبة، وكل دورةٍ كاملة شوط.
   وفي السعي يُسقَط الموضع على محور الصفا ← المروة، والشوط ببلوغ طرفٍ مخالفٍ للسابق.
   وتُهمَل العيّنات رديئة الدقّة والقفزات المفاجئة والمواضع البعيدة عن المطاف والمسعى.
3. **العدّاد اليدوي** — ظاهرٌ دائماً، وهو الحَكَم عند التعارض، ومعه زرّ تراجع.

> **الجهاز مُعينٌ على التذكّر لا حاكمٌ على العبادة.** ومن شكّ في عدد الأشواط بنى على
> اليقين وهو الأقلّ، كما هو مقرَّرٌ عند أهل العلم.

الموقع **يعمل كاملاً بلا ماركرات وبلا تحديد موقع** — كلاهما تحسينٌ للدقّة لا شرطٌ للتشغيل.

## المظهر واللغة

- **وضعان بهويّتين:** فاتحٌ بأبيض الرخام وأخضر الحرم، وداكنٌ بسواد كسوة الكعبة وذهب
  تطريزها. يتبع المظهر إعداد الجهاز افتراضياً، ويُحفظ اختيار المستخدم.
- **لغتان:** العربية والإنجليزية، والبنية قابلة لإضافة لغاتٍ أخرى بإضافة مدخلٍ في
  `window.LANGS` وكائن ترجمةٍ بنفس المفاتيح في `js/i18n.js`، دون تعديل أي ملفٍّ آخر.
- الآيات والأذكار بخط `Amiri Quran` بالتشكيل الكامل، والآيات بين قوسي التنصيص المُصحفي.

## الاختبار

الاختبار الميداني في مكّة متعذّر، فبُني **وضع محاكاة** بديلاً عنه:

```bash
node tools/test-tracking.js                    # منطق العدّ خارج المتصفّح — ١٦ اختباراً
NODE_PATH=$(npm root -g) node tools/test-ui.js # الواجهة في متصفّح حقيقي — ٣٧ اختباراً
```

ويمكن تجريب التتبّع يدوياً بفتح `guide.html?sim=1`، فيظهر شريطٌ يحقن مساراتٍ اصطناعية:
طوافٌ دائريٌّ حول الكعبة، وسعيٌ ذهاباً وإياباً على محور المسعى، وضجيجٌ يجب ألّا يُحتسب.

## الماركرات

الصور مولَّدةٌ برمجياً في `markers/`، ونقشُ كل معلَمٍ مختلفٌ عن الآخر اختلافاً بيّناً لأن
تتبّع الصور يعتمد على تمايز المعالم الزاوية.

```bash
NODE_PATH=$(npm root -g) node tools/make-markers.js      # توليد صور الماركرات

# تصريف targets.mind (يحتاج مجلّد dist من حزمة mind-ar)
curl -sSLo mind-ar.tgz https://registry.npmjs.org/mind-ar/-/mind-ar-1.2.2.tgz
tar -xzf mind-ar.tgz
NODE_PATH=$(npm root -g) node tools/compile-targets.js package/dist
```

**ترتيب الصور في `targets.mind` يجب أن يطابق `markers/order.json`** لأنه ترتيب
`targetIndex` في `js/guide.js`.

للاستعمال الفعلي داخل الحرم تُطبع هذه الصور وتُثبَّت عند المعالم الأربعة، أو تُستبدل بصور
معالمَ حقيقية تُصوَّر في الموقع ثم تُصرَّف بالطريقة نفسها.

## المعايرة الميدانية

إحداثيات المعالم في `window.CONFIG` أعلى `js/rites.js` **تقريبيةٌ مأخوذة من المصادر
الجغرافية العامّة**، وتحتاج معايرةً ميدانية لضبط العدّ التلقائي. تعديلها في ذلك الموضع
وحده يكفي، ومعها حدود قبول العيّنات (`MAX_ACCURACY_M`, `TAWAF_MAX_R`, ...).

## المصادر

- الموسوعة الفقهية — الدرر السنيّة، أبواب الطواف والسعي وصفة العمرة.
- مناسك الحج والعمرة — الشيخ محمد بن صالح العثيمين.
- التحقيق والإيضاح لكثير من مسائل الحج والعمرة والزيارة — الشيخ عبد العزيز بن باز.
- صفة حجّة النبي ﷺ كما في حديث جابر بن عبد الله عند مسلم.

**تنويه:** هذا الدليل للتذكير والإرشاد وليس فتوى. وقد وُسِم كل عملٍ بحكمه من ركنٍ أو
واجبٍ أو سنّةٍ لئلّا يُظنّ المستحبّ واجباً. وعند الإشكال فاسأل أهل العلم.
